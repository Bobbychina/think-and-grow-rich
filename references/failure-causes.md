# 30 条失败原因：诊断信号与处方

> 源自《思考致富》"你为什么会失败"一章的清单。原书列 31 条，本笔记收录 30 条（"不够专注"已并入"努力方向不专一"）。
> 用途：不逐条念给用户听，用来**反查**——先听他说，再回来对号。

分层：L1 目标 / L2 决断 / L3 执行 / L4 关系 / L5 认知 / L6 外部（只标注，不列待办）。

## L1 目标层

**1. 缺乏明确的人生目标**
- 原文："没有中心目的或明确目标可以为之奋斗的人，绝对没有成功的希望。"
- 信号：说"想变好"但说不出具体是什么；计划一周换一个；所有目标都停在"以后"。
- 处方：先写一个 90 天目标卡（六格），其余愿望全部标"暂缓"。

**2. 努力方向不专一**
- 原文："'万事通'很难有一己之长。要将所有精力集中在某个明确的主要目标上。"
- 信号：同时在学 3 门技能、做 3 个项目、开 3 条线；每条都刚起步。
- 处方：只留 1 条主线 + 最多 1 条副线，其余写进"停做清单"。

**3. 行业选择不当**
- 原文："谁也无法在不喜欢的行业获得成功……选择一个你能全身心投入的行业。"
- 信号：提起本职就疲倦；靠意志硬撑；总在看别的行业。
- 处方：先做"最小试验"（兼职/副项目/访谈 3 个从业者）再谈转行，不要在情绪最低点裸辞。

## L2 决断层

**4. 缺乏果断的决策力**
- 原文："成功者善于果断决策，即使改变决策，也改变得很慢；失败者即便决策，也决策得很慢，但改变起来既频繁又迅速。"
- 信号：小事也要问一圈人；决定后 3 天内反复推翻；用"再调研一下"无限延期。
- 处方：给每个决定设截止（小决定 48h，大决定 7 天）；改主意必须写理由和新增证据。

**5. 拖拉**
- 原文："大多数人一辈子失败的原因，是因为坐等'恰当时机'的来临……不存在'恰好'的时机。"
- 信号：任务总在截止前夜；准备时间远超执行时间。
- 处方：把任务砍到 15 分钟能开始的一步；用"手头工具现在做"替换"等我准备好"。

**6. 没有毅力**
- 原文：毅力是"习惯的直接产物"。
- 信号：开过很多头，收尾极少；一遇阻力就换目标。
- 处方：见 `persistence.md`——挑最弱的两个要素各配一个日常动作。

**7. 谨小慎微**
- 原文："力求完全的人只能在别人挑选完毕之后，随便捡一些剩下的东西。"
- 信号：方案改了十版还不敢发；要等"万无一失"。
- 处方：设"发布阈值"（够用就发，剩余问题列 backlog）；允许第一版难看。

**8. 无法控制"不劳而获"的欲望**
- 信号：问捷径、找风口、信"三天起号"；不愿付对等代价。
- 处方：把目标换算成"我需要提供多少有效服务"；砍掉所有零成本暴富方案。

## L3 执行层

**9. 缺乏自律**
- 原文："在控制环境之前，必须首先控制自己。如果你不征服自己，那么必然会被自己征服。"
- 信号：计划写得漂亮，作息和执行全乱；手机使用时间不受控。
- 处方：只锁一个环境变量（睡眠/起床/手机存放点），不求全面自律。

**10. 缺乏激情**
- 原文："没有激情就没有说服力。此外，激情能够传染。"
- 信号：表达平淡；做选择时"都行"；对结果无兴奋感。
- 处方：把目标和"他在乎的人/事"挂钩；每次汇报前先说"为什么这事值得做"。

**11. 身体不佳**
- 原文列举：吃太多不利健康的食物、错误思考习惯、精神消极、缺少锻炼、呼吸不当。
- 信号：长期熬夜、久坐、靠咖啡因硬撑、情绪随血糖波动。
- 处方：只改一件（睡眠时间或每天 20 分钟步行），持续 2 周再加下一件。

**12. 肆意挥霍**
- 原文："要养成将收入的固定比例存入银行……手头没有钱，你就必须听命于他人。"
- 信号：月光、无应急金、靠信用卡周转；也因此不敢辞职/不敢谈判。
- 处方：固定比例自动转存（哪怕 5%）；先攒 1 个月开支的"底气金"。

**13. 放纵**
- 信号：暴饮暴食、熬夜刷屏、成瘾性消遣占掉整块时间。
- 处方：不搞全面戒断，先给"放纵时段"设边界（时间盒）。

## L4 关系层

**14. 消极的个性**
- 原文："力量是通过与他人努力合作获得的。消极的个性不会吸引合作。"
- 信号：习惯性否定、抱怨、把问题归给别人；合作方逐渐远离。
- 处方：本周记录"否定 vs 建设性"发言比例；每次想否定时给一个替代方案。

**15. 没有与他人合作的能力**
- 信号：单干习惯；分工时抢活或不放心；冲突就断联。
- 处方：找一个小合作（一次联合交付），只练"分工 + 复盘"两件事。

**16. 选错事业伙伴**
- 原文："我们总是效仿那些和自己联系最紧密的人，所以要挑一个值得效仿的老板。"
- 信号：长期被拖后腿、背锅、价值观冲突。
- 处方：列"合作三问"（他是否可靠 / 是否让我变强 / 是否值得效仿），任一为否就降级关系。

**17. 结婚选错配偶**
- 说明：书里的原话；今天可扩展为"最亲密的长期关系"。
- 信号：家庭消耗持续侵蚀精力和决策自由。
- 处方：不替用户评判伴侣；只讨论"可协商的边界"与"精力预算"。

**18. 心胸狭隘**
- 原文："狭隘意味着你不再获得知识。"
- 信号：拒绝新方法；只跟同温层交流；把不同意见当攻击。
- 处方：每周主动接触一个"不同观点"的信息源，并写下对方最有力的一点。

## L5 认知层

**19. 受教育不足（不会用知识）**
- 原文："教育程度不在于学到多少知识，而在于有效而持久地运用知识。得到报酬的原因不只是我们懂得了多少，更因为我们利用知识做了些什么。"
- 信号：收藏夹塞满课程但不产出；学历焦虑；学了不用。
- 处方：选一个"学了就交付"的小项目，用输出倒逼输入。

**20. 臆断而不是思考**
- 信号：用"我觉得"代替数据；不做验证就下结论；把猜测当事实。
- 处方：每个关键判断写"证据 / 假设 / 待验证"，本周验证一条。

**21. 迷信与偏见**
- 信号：把成败归给运气、星座、风口；拒绝看统计。
- 处方：把"运气解释"改写成"可重复的动作清单"。

**22. 自负与虚荣**
- 信号：更在意显得厉害而非做成；听不进反馈；头衔敏感。
- 处方：每周请一个可信的人给一条负面反馈，只回"收到，我改哪一点"。

**23. 故意不诚实**
- 信号：夸大经历、数据注水、承诺不兑现。
- 处方：这条没有技巧，只有止损——先补一个真实交付，再谈增长。

**24. 通过自身努力以外的方式得到力量**
- 信号：指望关系、运气、平台红利，不愿练硬本事。
- 处方：把"我要认识谁"改成"我能为谁提供什么"。

## L6 外部层（只标注，不列待办）

**25. 倒霉的遗传背景** / **26. 小时候不合意环境的影响**
- 说明：书里列为首因，但它们不可选。处理方式：承认它影响起点，不承认它决定终点；把注意力放到**可改变的那一栏**。

**27. 缺少资金**
- 原文："你的经济要求或希望和实际价值毫无关系。你的实际价值完全建立在提供有效服务的能力……的基础上。"
- 说明：钱是结果不是原因。诊断时若用户只剩这一条，说明真正的问题是"服务能力/客户"没被验证。

**28. 恐惧** → 见 `fears.md`（单独一章）
**29. 消极影响（环境）** → 见 `principles.md`"人际影响"
**30. 找不到明确目标 / 缺乏雄心** → 见 L1（原文另列"缺少出人头地的雄心"：冷漠得不想超越他人，也没有成功希望）

## 用法提醒

- 一次诊断**不超过 5 条**，多了等于没诊断。
- 每条必须配证据；没有证据的条目写进"待观察"，不要硬塞。
- 结尾问："这几条里，哪一条你自己也认？"——他认的那条才是真正的入口。
