# 求职与推销服务：简历清单 + 七步法

> 源自《思考致富》"怎样得到渴望已久的职位"与"简历中应包含的个人信息"两节。
> 核心判断：原文说这套做法"往往能让你实现某个既定目标的时间缩短 1~5 年"。

## 一、简历六段清单

按顺序写，每段都被作者单独点过：

1. **教育背景** —— 在哪些学校上学、学过哪些专业，并给出**选择这些专业的具体原因**。
2. **工作经历** —— 有类似岗位经历就完整写出，明确而肯定地写出自己的专长。
3. **申请的具体职位** —— 必须点明。
   - 反面示例（原文）："申请一个位子即可" → 这说明你缺少专业资质。
4. **专业资质** —— 详细说明为什么相信自己有资格得到这个具体职位。
   - 原文判断：**"这是求职申请中最重要的细节，比任何其他因素都更能决定你将收到多少重视。"**
5. **业务了解** —— 对"准"老板所经营的业务做充分调研，在简历里透出你懂这一行。原文：这种做法会给对方留下深刻印象，因为它表示你对追求的职位确实感兴趣。
6. **零错误** —— "简历一旦完成，要一丝不苟地检查有无拼写和语法错误。"

## 二、得到职位的七步法

1. **准确定位**：准确决定你希望从事什么工作；如果当前不存在这种工作，**或许你能独创它**。
2. **选对象**：挑选你想在其中工作的公司，或你希望为其效力的人。
3. **做调研**：研究准老板的就业政策、人事安排和晋升机会。
4. **自析**：分析自己的天赋与能力，搞清楚你能提供什么，然后想办法展示优势、服务、推动作用和精妙的点子。
5. **换问法**：不要老想着"有份工作"就行，也不要琢磨"能给我一个职位吗"——**注重你能做点什么**。
6. **写下来**：计划一旦成形，就变成条理清楚、内容详实的文字。
7. **递给决策者**：呈现给有决策权的当权派。原文："只要你能拿出对公司有利的明显行动计划，公司肯定会有你的一席之地。"

## 三、试用期必答的三句话（面试/求职信里要能撑住）

原文明列，招聘方真正在评估的是这三条：

1. 你相信自己有能力胜任所申请的职位；
2. 你相信准老板会在试用结束后决定录取你；
3. 你**决心**得到所追求的职位。

## 四、调研表（填满再去投）

| 项 | 要查什么 | 写进简历/信里的形式 |
|---|---|---|
| 业务模式 | 靠什么赚钱、客户是谁 | 一句"我注意到你们在做 X，我的 Y 经验能直接接上" |
| 当前难题 | 最近在扩什么、裁什么、缺什么 | 一个具体建议或一个小方案 |
| 晋升路径 | 这个岗位往上走是什么 | 一句"我打算在这条线上做三年" |
| 决策人 | 谁拍板、谁影响 | 直递决策人，而不是海投 HR |
| 团队 | 你和谁共事、向谁汇报 | 说明你能补上团队缺的那块 |

## 五、一页行动计划模板

```
目标职位：____（具体到岗位名 + 公司）
我能提供的价值：____（一句，动词开头，可验证）
对方当前的问题：____（调研得来，不是猜的）
我的方案（30 天内可落地）：____
我的资质证据：____（作品/数据/经历，各一条）
我要求的条件：____（薪资/职级/时间，给区间 + 理由）
下一步动作：____（日期 + 找谁 + 递什么）
```

## 六、常见拒绝理由与真实原因

| 对方说 | 多半真实在说 | 你怎么改 |
|---|---|---|
| "经验不匹配" | 你没证明能立刻上手 | 补一段"同类问题我做过"的证据 |
| "再等等/看机会" | 你没让对方看到具体价值 | 给一个 30 天方案 |
| "我们要全能型" | 你没说清专长 | 收窄到一个最擅长的点 |
| 已读不回 | 简历没透出你懂这行 | 补调研段，重写第一屏 |

## 七、边界

- 不教用户编造经历（对应失败原因"故意不诚实"）。没有的就用"可迁移能力 + 快速学习证据"补。
- 不替用户决定要不要裸辞；先给"最小试验"路径（兼职/项目/访谈）。
- 谈薪属于博弈：只给"区间 + 理由 + 底线"三件套，不替他拍板。
