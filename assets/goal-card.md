# 目标卡

> 六格必填。缺哪格只问哪格，一次最多问 2 个。

```markdown
## 目标卡 · <一句话标题>

| 格 | 内容 |
|---|---|
| 动作（动词开头，一个） | |
| 对象（为谁 / 和谁） | |
| 场景（在哪、什么身份） | |
| 代价（时间 / 钱 / 放弃什么） | |
| 截止（具体日期） | |
| 验收（怎么算做到，谁来看） | |

### 90 天里程碑
- 第 1 个 30 天：
- 第 2 个 30 天：
- 第 3 个 30 天：

### 停做清单（为腾出时间砍掉的事）
-
-
```

## 检查

- [ ] 动作是动词，不是名词（"写完"不是"写作"）
- [ ] 验收标准有**第三方可验证**的证据
- [ ] 截止日期是日期，不是"今年"
- [ ] 没有"尽量 / 争取 / 希望"这类词
