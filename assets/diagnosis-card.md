# 诊断卡

> §3 收口用。命中 3–5 条，每条必须有证据；只保留一条主根因链。

```markdown
## 诊断卡 · <日期>

**目标卡一句话**：____

### 命中项
| # | 失败原因（原文短引） | 层级 | 证据（用户原话/行为） | 可控 |
|---|---|---|---|---|
| 1 | | L? | | 是/否 |
| 2 | | L? | | 是/否 |
| 3 | | L? | | 是/否 |

### 主根因链
`恐惧/信念（L?） → 行为（L?） → 结果（L?）`

### 不归我控制（只标注）
-

### 这周只做 3 件
1.
2.
3.

### 用户认领
"这几条里，我自己也认的是：____"
```

## 纪律

- 没有证据的条目放"待观察"，不硬塞。
- 用户否认就撤回，不争论。
- 3 件行动都要能在 7 天内看到证据。
